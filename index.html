  1. Connect the receiver to the computer with the USB cable.
  2. Press Install and pick the receiver's port.
  3. When asked about erasing: yes for a new board, no for a receiver already in use.
  4. Wait until writing is over: the receiver restarts by itself.
Cancellare un ricevitore già in uso toglie profili, reti WiFi e caster: si ripartirebbe dalle impostazioni di fabbrica. Per aggiornarlo basta il pannello del ricevitore. Erasing a receiver already in use removes its profiles, WiFi networks and casters: it would start again from factory settings. To update it, its own configuration page is enough.
